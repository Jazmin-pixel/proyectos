# Testigo Ocular

Juego de memoria desarrollado con **Vite + TypeScript** y probado con **Vitest**. 

## Descripción
El jugador cuenta con 5 segundos para observar una escena con objetos aleatorios. Posteriormente, debe responder preguntas de memoria para comprobar si los objetos estaban presentes o ausentes.
